# Zonaprop 阿根廷房产数据集样本

此 **Zonaprop 阿根廷房产数据集样本**包含 **1,775 条记录**，并使用 **Bright Data API** 提取。

## 数据字段

| 字段名称 | 描述 |
|------------|-------------|
| `url` | Zonaprop 上房产信息的直接 URL。 |
| `Title` | 卖家提供的房产信息标题。 |
| `generatedTitle` | 自动生成的房产信息标题。 |
| `Imagenes` | 指向房产图片的 URL 列表。 |
| `Numero_de_imagenes` | 房产信息中可用的图片数量。 |
| `Description` | 房产的详细描述，包括特色和配套设施。 |
| `Precio` | 房产的挂牌价格。 |
| `Currency` | 房产挂牌价格所使用的货币。 |
| `Fecha_de_publicacion` | 房产信息的发布日期。 |
| `Visualizaciones` | 房产信息的浏览次数。 |
| `Dimension_terreno` | 房产的土地面积，以平方米为单位。 |
| `Dimension_propiedad` | 房产本身的面积，以平方米为单位。 |
| `Ambientes` | 房产中的房间或空间数量。 |
| `Banos` | 房产中的卫生间数量。 |
| `Dormitorios` | 房产中的卧室数量。 |
| `Tipo` | 房产类型，例如公寓、住宅或土地。 |
| `Nueva_usada` | 表示房产是新房还是二手房。 |
| `Tipovendedor` | 卖家类型，例如业主或房地产中介。 |
| `Seller_name` | 发布该房产信息的卖家或房地产中介名称。 |
| `Seller_ID` | 卖家或房地产中介的唯一标识符。 |
| `Seller_url` | 卖家或中介在 Zonaprop 上的个人资料 URL。 |
| `Phone1` | 卖家或中介的主要联系电话。 |
| `Phone2` | 卖家或中介的备用联系电话。 |
| `Operacion` | 交易类型，例如出售或出租。 |
| `Zona` | 房产所在的主要区域或地区。 |
| `Zona2` | 房产所在地的次级区域或更具体的地区。 |
| `Zona3` | 房产的其他位置信息。 |
| `developmentFeatures` | 与房地产开发相关的特色和配套设施。 |
| `Superdestacado` | 表示该房产是否为重点推荐信息。 |
| `Premium_label` | 表示该房产是否具备高级特色的标签。 |
| `posting_id` | 房产信息的唯一标识符。 |
| `proveedor_tour` | 房产虚拟看房服务的提供商（如有）。 |
| `estatus` | 房产信息的当前状态。 |
| `latitude` | 房产所在位置的纬度坐标。 |
| `longitude` | 房产所在位置的经度坐标。 |
| `address` | 房产的完整地址。 |
| `seller_level` | 卖家或中介的等级或评分。 |
| `expenses` | 与房产相关的费用或收费。 |


## 使用场景

### 1. 房地产市场分析
利用此数据集分析阿根廷房地产市场的趋势，了解价格动态和房源供应情况。

### 2. 投资机会识别
通过分析阿根廷不同区域的房产特征和价格，识别潜在投资机会。

### 3. 房地产中介竞争分析
房地产中介可以利用这些数据分析竞争对手的房源信息，从而提升自身在市场中的战略定位。
